Product Requirements Companion — Status: Approved

bAssistant

Zero-backend React SPA deployed to Cloudflare Pages. Empowers visiting LLMs via WebMCP with live canvas diagramming, in-browser LiteParse + BM25 local doc querying, and free research tools.

The Core User & Agent Journey

WebMCP Exposed Tool Suite

search_web
DuckDuckGo search (via DDGS) returning relevant web summaries.
search_research
ArXiv paper search returning title, authors, and abstracts.
calculate
Evaluates decimal math expressions accurately.
search_document
Queries uploaded document chunks in IndexedDB using BM25.
clean_document
Purges stored document chunks from IndexedDB and resets upload box.
get_chat_history
Returns dialogue stream containing user messages prefixed with "user:".
canvas_draw
Renders shapes, lines, text, flowcharts, and diagrams on the HTML canvas.
canvas_clear
Wipes the canvas clean (also accessible via UI Clear Canvas button).
chat_post
Appends or streams agent responses into the 40% chat area.
get_tool_usage_prompt
Read-only, zero-arg: returns the agent operating guide explaining how to use every other tool. Agents call it first.
canvas2d_draw_shapes
Appends structured scene-graph shapes (rectangles, ellipses, diamonds, text, stickers) with arrows that stay attached to nodes.
canvas2d_inspect_shapes
Returns the active scene graph and an ASCII topology graph so agents can inspect layout before modifying.
canvas2d_modify_shape
Targeted in-place edits (label, colors, position) by nodeId, keeping connected arrows attached.
canvas2d_clear
Resets all shapes from the Canvas2D scene graph.
draw_diagram
Draws a connected flowchart or architecture graph with labeled edges.
export_pdf
Generates the multilingual session PDF: canvas snapshot + humanized chat transcript. Blank sessions are rejected with a popup.

Key States and Boundaries

1 Initial & Blank State

Both the HTML canvas (top 60%) and chat area (bottom 40%) start completely blank. File upload dropzone is empty. Theme applies based on Light/Dark toggle in branding header.

2 File Upload Processing & Success

When user selects/drops Doc or PDF < 1MB: LiteParse WASM parses pages client-side, builds BM25 index in IndexedDB, and UI updates with filename, total page count, and an "Indexed" badge.

3 File Upload Rejection (Error State)

If user selects a file ≥ 1MB or unsupported format: A notification popup explains the exact rejection reason. The upload input resets cleanly without error.

4 Storage Reset (clean_document)

When clean_document is invoked by agent or user: IndexedDB tables are cleared and the file upload UI immediately returns to its empty initial state.

5 Chat Flow & User Prefix

User types in the bottom text input. Sent messages appear in chat with user: prefix and are made available to visiting LLMs via get_chat_history. Agent responses are humanized (raw markdown asterisk noise stripped) for executive readability.

6 PDF Export & Blank Session Protection

When export_pdf is invoked (sidebar button or tool): if the session is blank (no canvas content and no chat messages), a notification popup blocks the export. Otherwise a dual-section PDF downloads with the canvas snapshot on top and the chat transcript beneath, including native Bengali and Hindi complex-script rendering.
