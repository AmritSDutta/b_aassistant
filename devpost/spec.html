Technical Spec Companion — Status: Approved

bAssistant — Technical Blueprint

Zero-backend React + Vite SPA on Cloudflare Pages. Multimodal WebMCP tool provider with LiteParse WASM, IndexedDB BM25 search, and HTML canvas graphics engine.

System Architecture & Data Flow

Component Breakdown

App.tsx

Root container managing 20/80 screen division, light/dark theme state, and WebMCP provider initialization.

FileUpload.tsx

Dropzone validating <1MB doc/PDF, triggering LiteParse WASM, and displaying page count + "Indexed" badge.

CanvasArea.tsx

Top 60% HTML5 canvas with Clear Canvas and Export PDF controls. Connects to canvasEngine.ts for scene-graph rendering.

ChatArea.tsx + HumanizedMessage.tsx

Bottom 40% chat stream showing user: messages and agent posts. HumanizedMessage strips raw markdown asterisk noise for executive readability.

WebMCPProvider.ts

Unified bridge exposing all 16 tools on six surfaces: document.modelContext, navigator.modelContext, window.webmcp, hidden DOM forms, postMessage JSON-RPC 2.0, and ready custom events. Forwards readOnlyHint annotations.

pdfExportService.ts

Multilingual dual-section PDF export: canvas snapshot + cleaned chat transcript, with 3x HiDPI rasterization for Bengali/Hindi complex scripts and blank-session protection.

Data & Persistence

IndexedDB (bAssistantDB)

Stores documents metadata, pagewise chunks from LiteParse WASM, and BM25 index inverted index map.

BM25 Client Search

Pure TypeScript BM25 indexer calculating term frequencies and document lengths for lexical chunk search.

Local Storage

Stores user's Light/Dark mode preference across browser sessions.

clean_document Tool

Purges all IndexedDB stores and resets upload state back to empty.
