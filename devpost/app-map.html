bAssistant - Visual App Map & Tour

Build with AI Basics Hackathon - Final Deliverable

A zero-backend browser assistant empowering visiting LLMs via standard browser WebMCP with live canvas diagramming, local document querying (LiteParse WASM + BM25 in IndexedDB), and research tools.

1. UI Architecture & Viewport Split

Left Sidebar (20%)

Hosts Branding (title, logo, theme toggle), FileUpload (< 1MB Doc/PDF dropzone, page count, "Indexed" badge, rejection modal), and a reserved BlankSlot.

src/components/Branding.tsx
src/components/FileUpload.tsx

Top Canvas Area (60% pane)

Artistic 2D HTML5 canvas engine with Rough.js hand-drawn sketching, fluid Bézier connectors, paper backdrop, and Risograph palettes. Renders shapes, connectors, and graphs dynamically via LLM tool calls. Includes toolbar controls.

src/components/CanvasArea.tsx
src/lib/canvasEngine.ts

Bottom Chat Area (40% pane)

Dialogue stream with user: prefixed user messages and agent streaming. Supports direct user typing and WebMCP agent posting.

src/components/ChatArea.tsx

2. Multi-Standard WebMCP Suite

Tool Input Arguments Purpose / Action
get_chat_history {} Retrieves recent messages with user: prefixing.
chat_post { text: string } Appends agent explanation into the chat dialogue stream.
canvas_draw { command: object } Renders 2D diagram primitives (rect, circle, line, text, graph).
canvas_clear {} Clears all canvas drawings.
search_document { query: string } Queries IndexedDB using client-side BM25 relevance scoring.
clean_document {} Purges stored chunks and BM25 index from IndexedDB.
search_web { query: string } Queries DuckDuckGo CORS API for web summaries.
search_research { query: string } Queries ArXiv public API for academic preprints.
calculate { expression: string } Evaluates decimal math with floating-point precision correction.

3. Local Data Engine & Privacy

LiteParse WASM

Zero-backend browser parser extracting text & page counts without sending files to any server.

src/lib/liteparseService.ts

IndexedDB (bAssistantDB)

Stores documents, chunks, and bm25_index locally in the browser sandbox.

BM25 Lexical Scorer

Inverted index scoring term frequency against normalized document length with k1=1.5 and b=0.75.
