WebMCP Browser Assistant

A zero-backend single-page workspace empowering visiting LLMs with WebMCP tools for live canvas diagramming, local document querying, and free-tier research.

The Core Architecture & Loop

The single-page application is split strictly 20% (left sidebar: branding, <1MB file upload with pagewise BM25 indexing, blank slot) and 80% (right main area: 60% top canvas, 40% bottom chat). Visiting agents interact with the page purely through exposed WebMCP tools.

The Unique Kernel

Replaces costly generative image/video models with fast, free programmatic HTML canvas drawing tools. Provides zero-backend local document privacy (pagewise BM25 index) and free-tier web/academic tools for any visiting model.

What "Working" Looks Like

A user opens the single page, uploads a doc/PDF (< 1MB) which is pagewise-chunked and indexed via BM25, and activates WebMCP Inspector testing mode. The inspector verifies exposed tools, and a test run showcases live diagram drawing and synchronized chat output.

Proof of Concept Boundary

NOW (In Scope for PoC)
  • React-based single-page application with responsive layout (20/80 vertical division).
  • Left sidebar: Branding, File upload (Doc/PDF < 1MB only), Blank 3rd section.
  • Right main view: Top 60% HTML Canvas with structured scene-graph drawing engine, Bottom 40% Chat display.
  • Post-upload processing: In-browser pagewise chunking using LiteParse (browser WASM) and client-side BM25 searchable index in IndexedDB for files < 1MB.
  • WebMCP Tool Suite (16 tools):
    • get_tool_usage_prompt (read-only, zero-arg: returns the agent operating guide for using all other tools — call first)
    • search_web (DuckDuckGo / DDGS)
    • search_research (ArXiv search)
    • calculate (decimal math)
    • search_document (IndexedDB BM25 content search)
    • clean_document (removes stored content from IndexedDB)
    • Canvas2D scene-graph tools: canvas2d_draw_shapes, canvas2d_inspect_shapes, canvas2d_modify_shape, canvas2d_clear
    • Legacy canvas tools: canvas_draw, draw_diagram, canvas_clear
    • Chat tools: chat_post, get_chat_history (bottom 40% chat)
    • export_pdf (multilingual canvas + transcript PDF report)
  • Multilingual PDF export (canvas snapshot + humanized chat transcript, native Bengali/Hindi complex-script rendering, blank-session protection).
  • Long-dwell UI enrichment (see research.md): warm token dual themes, first-load onboarding popup, chat full-screen reader popup, A-/A+ font steps, reading-progress bar, Session Highlights in sidebar Section 3, thinking pulse, copy/star message actions, drag-over feedback, session strip, reduced-motion support.
  • WebMCP Inspector testing mode for live validation and tool calling.
  • Deployment: Deployed to Cloudflare Pages.
LATER (Future Phases)
  • Additional free-tier tools as project progresses.
  • Features for the 3rd (blank) sidebar section.
CUT (Explicitly Excluded)
  • Files ≥ 2MB: Strictly rejected; only doc and PDF files under 2MB accepted.
  • MCP server endpoint integration: Out of scope for this iteration; operates 100% in-browser via WebMCP client protocols without external backend SSE/stdio MCP servers.
  • Image, audio, or video data integration: Out of scope for this iteration; ingestion and processing are focused strictly on text documents and web references.
  • Backend server / database: Purely in-browser; zero cloud infrastructure needed.
  • Direct generative image/video models: Replaced by programmatic canvas graphics.
  • In-app API key billing: Connection responsibility sits with the visiting agent.
