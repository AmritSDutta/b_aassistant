# WebMCP Integration

bAssistant implements multi-standard WebMCP support to maximize compatibility with visiting AI assistants, inspector extensions, and client scripts.

## Registered Standards

1. **`navigator.modelContext`**: Emerging browser standard for AI context injection.
2. **`window.webmcp`**: Direct JavaScript bridge object offering `listTools()` and `callTool(name, args)`.
3. **`postMessage` (JSON-RPC 2.0)**: Standard cross-window event interface (`tools/list` and `tools/call`).
4. **CustomEvents**: Emits `webmcp:ready` upon initialization.

## Tool Suite Overview

| Tool | Parameters | Description |
| :--- | :--- | :--- |
| `get_chat_history` | `{}` | Returns recent dialogue history with user messages prefixed by `user:`. |
| `chat_post` | `{ text: string }` | Posts textual responses, markdown, or status updates to the chat area for the visiting LLM. |
| `canvas_draw` | `{ command?: object, commands?: object[] }` | Draws shapes (`rect`, `circle`, `line`, `text`, `graph`) in single or batch mode. |
| `draw_diagram` | `{ nodes: object[], edges: object[], title?: string, clearFirst?: boolean }` | Draws a high-level connected flowchart or concept diagram with nodes and labeled edges. |
| `canvas_clear` | `{}` | Clears all drawings from the canvas. |
| `search_document` | `{ query: string }` | Queries IndexedDB using client-side BM25. Removes stop words and returns the top 3 pages. Recommend passing targeted keywords rather than conversational questions. |
| `clean_document` | `{}` | Purges IndexedDB tables and resets document UI. |
| `search_web` | `{ query: string }` | Queries DuckDuckGo for web summaries. |
| `search_research` | `{ query: string }` | Queries ArXiv for scientific preprints. |
| `calculate` | `{ expression: string }` | Evaluates decimal math with floating-point correction. |
