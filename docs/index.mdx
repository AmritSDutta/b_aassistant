# bAssistant

**bAssistant** is an entirely client-side browser cockpit deployed on Cloudflare Pages. It equips visiting AI models and WebMCP clients with live visual diagramming, local document search over IndexedDB with BM25, and free research tools.

## Key Features

- **Strict 20/80 Layout**: 20% left sidebar for branding, upload, and export; 80% main area split into a 60% HTML5 canvas and 40% chat area.
- **Unified WebMCP Provider**: Simultaneous support for `document.modelContext`, `navigator.modelContext`, `window.webmcp`, and `postMessage` JSON-RPC 2.0 with 17 registered tools and agent guide.
- **100% Private Document Ingestion**: Parses Doc/PDF files under 2MB client-side via LiteParse WASM and indexes chunks with BM25 into browser IndexedDB.
- **Live Artistic Canvas2D Scene Graph**: Visiting LLMs draw and mutate persistent shapes, containers, connectors, and callouts with perimeter docking — rendered with Rough.js hand-drawn sketching and calibrated per theme — while users pan, wheel-zoom, Fit View, and Reset the viewport. See [Canvas2D Scene Graph](/canvas-and-pdf).
- **Session Vault & Local Persistence**: Every deliberation turn is recorded in IndexedDB; browse, restore, export, or delete past sessions from the vault, and reloads rehydrate the chat stream and canvas scene graph. See [Session Vault](/sessions-vault).
- **Long-Dwell UI & Ergonomics**: Warm paper/ink semantic tokens, full-screen reader view, A-/A+ font scale, reading-progress bar, reference URL cache, and star highlights revisit loop.
- **Humanized Chat Stream**: Eliminates raw markdown syntax asterisks and noise for an elegant reading experience.
- **Multilingual Client PDF Reports**: Exports dual-section executive PDFs with HiDPI canvas snapshot and chat transcript, featuring native Bengali (বাংলা) and Hindi (हिन्दी) font shaping and blank content protection.
- **Free Research & Math Tools**: Keyless Tavily AI web search with automatic DuckDuckGo fallback, plus ArXiv research lookups, served through a same-origin `/api` proxy (dev proxy + Cloudflare Pages Functions), plus reference URL context retrieval and decimal math calculations. See [Research & Math Tools](/research-tools).
- **Full-Duplex Live Voice Agent**: A bidirectional Gemini Live audio session with mid-dialogue WebMCP tool access, a decoupled two-tier agent topology (live orchestrator + background subagent), client-side AES-GCM-256 key encryption, and a sessionStorage-backed background task layer. See [Full-Duplex Live Voice Agent](/voice-agent).
