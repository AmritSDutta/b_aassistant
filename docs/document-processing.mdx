# In-Browser Document Processing

bAssistant prioritizes privacy by ensuring all document ingestion and search operations happen inside the user's browser sandbox.

## Constraints

- **File Formats**: `.pdf`, `.doc`, `.docx`
- **Maximum File Size**: Strictly `< 1MB`
- Any file exceeding 1MB or of an unsupported format is rejected with a clear notification popup modal.

## Processing Pipeline

1. **Upload & Validation**: Validates size (< 1MB) and extension in `FileUpload.tsx`.
2. **LiteParse WASM / Stream Extraction**: Extracts natural 1:1 page text via WebAssembly (`@llamaindex/liteparse-wasm`) with high-performance native browser stream decompression (`DecompressionStream('deflate-raw')`) without arbitrary character slicing.
3. **BM25 Lexical Indexing**: Tokenizes text, computes term frequencies, document frequencies, and average document lengths across natural pages.
4. **IndexedDB Persistence**: Stores document metadata, chunks, and the inverted BM25 index in `bAssistantDB`.
5. **Agent Retrieval**: Visiting models query `search_document`. Queries automatically have conversational stop words stripped, leverage keyword-guided descriptions, and return strictly the top 3 most relevant pages.
